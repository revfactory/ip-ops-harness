# 주장 검증 기준(evidence-verifier용)

검증자는 주장이 중요한지, 결론이 그럴듯한지 보지 않는다. **근거가 실제로 그 말을 하는지, 그 근거가 얼마나 단단한지**만 본다. 판정은 심사위원이 한다.

## 1. 절차

1. 주장의 `evidence`와 `source_file`을 보고 근거 위치(신호 카드 줄, 출처 URL)를 찾는다.
2. 원문을 직접 연다. 신호 카드의 표를 다시 읽는 것은 재확인이 아니다.
3. 주어진 관점으로 판정한다.
4. 주장마다 결과 한 줄을 반환한다. 받은 id를 하나도 빠뜨리지 않는다.

## 2. 관점

| 관점 | 확인할 것 |
| --- | --- |
| 출처·숫자 | 숫자·단위·날짜·주체(누가 발표했나, 어느 회사인가)가 원문과 같은가. 억·만 단위, 회차 시청률과 순간 시청률, 누적 조회와 독자 수를 구분했는가 |
| 논리·반대 근거 | 근거가 사실이어도 주장까지 이어지는가(예: 전시 매진 → 공연 수요는 비약일 수 있다). 같은 원문이나 다른 A·B등급 자료에 더 강한 반대 근거가 있는가 |
| 둘 다 | 표준 실행에서는 한 검증자가 두 관점을 모두 본다 |

## 3. 상태

| 상태 | 언제 |
| --- | --- |
| `confirmed` | 원문이 주장을 직접 뒷받침하고, 관점의 확인 사항에 걸리는 것이 없다 |
| `refuted` | 원문이 주장과 다르다(숫자·단위·주체 오류), 이미 실행된 확장을 새 제안처럼 썼다, 근거로 든 자료가 존재하지 않는다, 더 강한 반대 근거가 주장을 뒤집는다 |
| `uncertain` | 원문을 열 수 없다, 근거가 C등급뿐이다, 근거가 유사작·구조 추론이다, 내부 데이터로만 확인할 수 있다 |

`refuted`면 메모에 맞는 값이나 반대 근거를 적는다. 심사위원이 그 메모로 판정문을 고친다.

## 4. 출처 등급(best_source_grade)

주장을 뒷받침하는 출처 가운데 가장 강한 것의 등급을 적는다. 등급 기준은 `ent-research` 스킬 「2. 출처 등급」과 같다. 원문을 열지 못했으면 `none`이다. 내부 지표 주장(id가 `D-`로 시작)은 `internal_metrics.json` 값과 일치하면 `A`로 본다.

## 5. 반환 예시

```json
{ "results": [
  { "id": "P-03", "status": "refuted", "best_source_grade": "A",
    "note": "체험 전시·굿즈샵은 2025년에 이미 실행됨. 새 제안으로 쓸 수 없음",
    "url": "https://www.hankyung.com/article/2025101626907" },
  { "id": "G-02", "status": "uncertain", "best_source_grade": "C",
    "note": "영어권 수요 근거가 팬 창작물 편수뿐. 독자 수가 아님" }
] }
```
