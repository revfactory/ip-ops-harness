# 권리와 수익 구조 점검

CIPO의 7번 과제는 "어떤 권리를 확보해야 후속 사업에서 더 많은 수익을 가져갈 수 있는가"다. 계약 내용은 대부분 비공개이므로 이 스킬의 산출물은 **결론이 아니라 확인 질문**이다. 무엇을 물어야 하는지 정확히 아는 것만으로 협상 준비가 빨라진다. 판정 전체가 권리 가정 위에 서 있을 때가 많으므로, 그 가정을 드러내는 것도 이 스킬의 일이다.

## 1. 권리 점검표

| 권리 | 필요한 확장 | 공개 자료로 볼 수 있는 단서 |
| --- | --- | --- |
| 2차적저작물작성권(웹소설→웹툰 등) | 노블코믹스, 스핀오프 | 웹툰 제작사·공동 제작 표기 |
| 영상화권(드라마·영화·애니) | 영상 | 제작사·투자사 발표, 크레딧 |
| 해외 출판·번역권 | 해외 웹툰·단행본 | 해외 플랫폼 서비스 주체, 출판사 |
| 상품화권 | 굿즈, 팝업, 전시, 콜라보 | 공식 굿즈 판매 주체 |
| 게임 라이선스 | 게임 | 게임사 발표 |
| 공연권 | 뮤지컬, 쇼, 팬 콘서트 | 공연 제작사 발표 |
| 음악 권리(OST 저작권·저작인접권) | OST, 아티스트 협업 | 음원 크레딧, 유통사 |
| 퍼블리시티권·초상권 | 배우·아티스트가 결합된 굿즈·광고 | 소속사, 계약 보도 |
| 리메이크·포맷권 | 해외 리메이크 | 리메이크 발표 |
| AI 활용 허용 범위 | AI를 쓴 2차 콘텐츠·마케팅 소재 | 작가 계약·발행사 정책(대개 비공개) |

## 2. 확장 기획 모드(③)

### 수익 누수 지점
다음마다 "카카오엔터가 가져가는 몫이 줄어드는 구조"인지 확인할 질문을 만든다.

- 영상화를 외부 제작사가 하고 원작사는 판권료만 받는 경우
- 해외 판권을 지역 단위로 일괄 매각한 경우
- 굿즈·게임을 단발 라이선스로 넘긴 경우
- OST 권리가 드라마 제작사에 있는 경우
- 발행사(원천 플랫폼과 다른 회사)가 2차 사업 제안 창구인 경우

### 확보 우선순위
확장 지도의 1·2·3차 순서와 맞춘다. 1차 확장에 필요한 권리가 가장 급하다. 3차(공연·굿즈) 권리는 1차 성과 전에 확보하면 협상 위치가 좋다. 이 판단은 "추정"으로 표시한다.

### 창작자 관계
작가와의 수익 배분, 2차 사업 참여 의사, 작가의 해석 권한은 IP의 장기 가치와 연결된다. 확인 질문에 반드시 넣는다. 작가가 휴재·투병 중이면 작가에게 직접 연락하라는 질문을 쓰지 않고, 내부 계약과 사업 담당 경로로 쓴다.

### 출력 형식
```markdown
# {IP명} 권리·수익 점검 ({YYYY-MM-DD}, {n}차)
> 사업 검토용 점검표다. 법률 판단이 아니며, 계약 내용은 내부 확인이 필요하다.
## 한 줄 결론
## 판정이 기대는 권리 가정
## 포맷별 필요 권리
| 확장 포맷 | 필요 권리 | 공개 확인 상태(확인·추정·비공개) | 근거 | 확인 질문 |
## 수익 구조 메모
## 확보 우선순위(추정)
## 내부 확인 질문 목록
- [ ] 법무: ...
- [ ] 사업: ...
- [ ] 창작자 관계(사업 담당 경유): ...
```

## 3. 권리 범위 모드(⑤)

제작 준비물(피치 자료·콘티·마케팅 소재 요청서)이 확인된 권리 범위 안에 있는지 본다.

1. 오케스트레이터가 프롬프트에 붙여 준 판정 원장 기록(`ledger.py show --ip {ip}` 출력)에서 법무 확인 결과(결정 기록의 메모)를, 최신 `22_rights_revenue.md`에서 확인 상태를 모은다. 원장 기록이 프롬프트에 없으면 오케스트레이터에게 요청한다.
2. 준비물이 쓰는 권리를 항목별로 뽑는다: 포맷, 지역, 매체, 상품화(굿즈·MD), 음악, 퍼블리시티, AI 활용.
3. 항목마다 `확인됨 / 미확인 / 불가`를 매기고, 미확인·불가에 기대는 요소를 준비물의 위치(장·씬)와 함께 적는다.

```markdown
# {IP명} {포맷} 준비물 권리 범위 점검 ({YYYY-MM-DD})
> 사업 검토용이다. 법률 판단이 아니다.
## 한 줄 결론
| 준비물 위치 | 쓰는 권리 | 상태(확인됨·미확인·불가) | 근거 | 조치 제안 |
## 법무에 새로 물을 질문
```
