# 유통 실행 계획

유통 계획은 새 판단을 하지 않는다. 판정문의 시작 조건과 글로벌 진단의 첫 진출 추천을 **누가, 언제, 무엇을 확인한 뒤, 무엇을 내보내는가**로 바꾼다. 조건이 충족되지 않은 시장을 일정표에 앞당겨 넣는 순간 판정을 뒤집는 셈이 된다.

## 1. 진출 국가·채널·시점 후보

| 순서 | 시장 | 채널(플랫폼·파트너) | 진입 포맷 | 시작 조건(판정문 그대로) | 조건 충족 여부 | 권리 상태 | 결정하는 사람 |

- 시작 조건은 판정문 문장을 그대로 옮긴다.
- 권리 미확인 지역·매체는 `[권리 미확인]`을 붙이고 표 맨 뒤에 둔다.
- 별도 법인(카카오픽코마 등)이 채널이면 "법인 간 협의 필요"를 적는다.
- 휴재·작가 사정 같은 발표 제약이 판정문에 있으면 시점 칸에 반영한다.

## 2. 현지화 점검표

| 항목 | 시장 | 바꿀 것 | 바꾸면 안 되는 것 | 담당 | 사람 검수 |

제목, 고유 명사 표기(설정집 `glossary.md` 기준), 표현 수위, 문화 코드 설명, 분량·공개 주기, 마케팅 문구가 기본 항목이다. 번역·더빙에 AI를 쓸지는 파트너 정책과 업계 입장이 갈린다. 쓰더라도 사람 검수를 전제로 하고, 파트너가 AI 번역을 받지 않으면 그 사실을 적는다.

## 3. 마케팅 소재 요청서

사내 도구(헬릭스 숏츠 등)에 넘길 요청서다. 실제 입력 양식은 공개 자료로 알 수 없으므로 아래 일반 양식으로 쓰고 "사내 양식 확인 필요"를 표시한다.

```markdown
## 마케팅 소재 요청서 — {IP명} / {시장} / {YYYY-MM-DD}
- 목적: (예: 일본 정식판 런칭 첫 4주 신규 독자 유입)
- 타깃: 원작 팬 / 새 독자, 근거
- 소재 형식·규격: (예: 세로 15초·30초, 자막 언어)
- 장면 후보: | 장면 | 원작 회차 | 쓰는 이유 | 스포일러 수준 |
- 핵심 문구 후보(현지화 전 원문)
- 금지 사항: 결말·반전 노출, 권리 미확인 요소(캐릭터 상품 이미지 등), AI 생성 이미지 사용 여부(기본: 사용 안 함), 휴재 중 발표 문구
- 검수: 원작 일관성(canon-check), 현지 표현(사람 검수)
- 성과 측정: 아래 추적 지표의 어느 값과 연결되는가
```

## 4. 추적 지표(⑦로 넘김)

| 지표 | 정의 | 측정 시점(시작 전 정함) | 데이터 출처 | 확대·중단 기준 |

- 국가별 열람·신규 독자, 유료 전환, 원작 역유입(원작 열람·거래액 변화), 소재별 반응을 기본으로 둔다.
- **측정 기간은 결과를 보기 전에 정한다.** 결과를 본 뒤 고른 기간의 배수는 과장된다.
- 확대·중단 기준은 global-fit의 "확대 판단 기준"과 맞춘다.

## 5. 출력 형식

```markdown
# {IP명} 유통 실행 계획 ({YYYY-MM-DD})
> {판정 회의 결정 반영 / 판정 회의 결정 전 초안}
## 한 줄 요약
## 1. 진출 후보와 시작 조건
## 2. 현지화 점검표
## 3. 마케팅 소재 요청서
## 4. 추적 지표
## 사람이 결정할 것 — 진출 국가와 시점, 번역 검수 책임, 소재 승인
## 수정 기록
```
