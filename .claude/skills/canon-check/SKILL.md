# 원작 일관성 검수

검수의 기준은 설정집이다. 검수자의 기억이나 취향이 아니다. 근거 없는 지적은 제작진이 검수를 믿지 않게 만들고, 의도된 각색을 오류로 모는 지적은 창작을 막는다.

## 1. 검수 범주

| 범주 | 확인할 것 | 자주 나오는 오류 |
| --- | --- | --- |
| 캐릭터 | 성격·말투·능력·외형이 해당 시점의 설정과 같은가 | 나중 회차에서 얻는 능력을 앞 시점에 씀, 말투 변화 |
| 관계 | 관계 상태가 그 시점에 맞는가 | 아직 만나지 않은 인물이 아는 사이로 나옴 |
| 세계관 규칙 | 규칙과 예외를 지키는가 | 규칙을 어기는데 대가가 없음 |
| 연표 | 사건 순서와 작중 시간이 맞는가 | 회상과 현재가 섞임 |
| 고유 명사 | 표기 사전과 같은가 | 금지 표기, 오타 |
| 상징·소품 | 상징의 의미와 등장 시점이 맞는가 | 핵심 소품을 다른 의미로 씀 |
| 하지 않는 것 | 캐릭터 카드의 '하지 않는 것'을 어기는가 | 원작 팬이 가장 먼저 알아채는 위반 |

## 2. 지적 분류

| 유형 | 언제 | 조치 |
| --- | --- | --- |
| 오류 | 설정집 근거와 다르고, 준비물에 각색 표시가 없다 | 수정 요청 |
| 표시 없는 각색 | 의도적 변경으로 보이지만 `원작과 다르게 갈 곳`에 없다 | 각색이면 표시, 아니면 수정 |
| 각색 확인 | `원작과 다르게 갈 곳`에 적힌 변경이다 | 오류가 아니다. 원작 팬 위험만 평한다 |
| 설정집 보강 필요 | 설정집에 없는 내용이라 판단할 수 없다 | story-bible-keeper에게 넘긴다 |

## 3. 심각도

- **높음**: 원작 팬이 바로 알아챌 핵심 설정 위반(주인공의 '하지 않는 것' 위반, 세계관 핵심 규칙 위반, 사건 순서 역전)
- **중간**: 주변 설정 위반, 표기 오류가 반복됨
- **낮음**: 한 번 나오는 표기·소품 오류

설정집이 임시본이면 심각도를 한 단계씩 낮추고 `확인 필요`를 붙인다. 임시본은 원고 확인 전이라 기준 자체가 틀릴 수 있다.

## 4. 판정

| 판정 | 조건 |
| --- | --- |
| 통과 | 높음 0건, 중간 2건 이하 |
| 수정 후 통과 | 높음 0건, 중간 3건 이상 또는 표시 없는 각색이 있음 |
| 재작업 | 높음 1건 이상 |

## 5. 출력 형식

```markdown
# {IP명} {포맷} 일관성 검수 {n}회차 ({YYYY-MM-DD})
## 판정: {통과 / 수정 후 통과 / 재작업} — 한 줄 이유
## 이전 지적 반영 확인(2회차부터)
| 이전 번호 | 반영 여부 | 메모 |
## 지적
| # | 위치(파일·씬·컷) | 범주 | 유형 | 심각도 | 준비물 내용 | 설정집 근거(파일·항목·원작 회차) | 제안 |
## 각색 확인
| 변경 | 원작 팬 위험(상·중·하) | 이유 |
## 설정집 보강 필요
## 잘된 점(3개 이내)
```

같은 지적을 표현만 바꿔 반복하지 않는다. 2회차부터는 이전 지적의 반영 여부를 먼저 확인하고 새 문제만 추가한다.
