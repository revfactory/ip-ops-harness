# 설정집·세계관 사전

설정집은 두 사람을 위해 만든다. 원작을 다 읽을 시간이 없는 제작진, 그리고 준비물이 원작과 어긋났는지 판단해야 하는 검수자다. 둘 다 "어디에 그렇게 나와 있나"를 바로 찾을 수 있어야 하므로, **근거 없는 항목은 설정집에 들어가지 않는다.**

## 1. 파일 구성

`_workspace/ips/{ip}/prod-{format}/50_bible/` 아래에 둔다.

| 파일 | 내용 |
| --- | --- |
| `index.md` | 기준 원고(형식, 기준 회차, 받은 날짜), 임시본 여부, 파일 목록, 항목 수, 갱신 기록 |
| `characters.md` | 캐릭터별 카드 |
| `world.md` | 세계관 규칙, 장소, 조직, 능력·시스템, 금기 |
| `timeline.md` | 사건 연표(회차 순, 작중 시간 순이 다르면 둘 다) |
| `glossary.md` | 고유 명사 표기 사전(한국어 표기, 금지 표기, 해외 표기 후보 칸) |
| `open-questions.md` | 원작에서 확정되지 않은 설정, 원고끼리 충돌하는 설정 |

## 2. 항목 형식

### 캐릭터 카드
```markdown
## {이름} ({다른 호칭})
| 항목 | 내용 | 구분 | 근거 |
| 첫 등장 | ... | 원작 설정 | 웹소설 3화 |
| 외형 | ... | 원작 설정 | 웹소설 3화, 웹툰 2화(웹툰판에서 머리색 변경) |
| 성격 | ... | 해석 | 웹소설 10~15화 행동에서 추론 |
| 말투 | 짧은 인용 1~2개 | 원작 설정 | 웹소설 12화 |
| 능력·제약 | ... | 원작 설정 | ... |
| 관계 | {상대}: 관계, 바뀐 시점 | 원작 설정 | ... |
| 변화 지점 | 회차와 무엇이 바뀌었나 | 원작 설정 | ... |
| 하지 않는 것 | 이 캐릭터가 원작에서 하지 않는 행동(검수에 중요) | 해석 | ... |
```

- **구분** 열은 `원작 설정`(본문에 명시), `작가 공식`(작가 후기·공식 설정집), `해석`(행동에서 추론) 가운데 하나다. 해석을 원작 설정처럼 쓰면 검수 기준이 틀어진다.
- 웹툰·드라마 같은 파생작에서 달라진 설정은 근거 칸에 파생작 회차와 차이를 적는다.

### 세계관 규칙
`규칙 | 예외 | 처음 드러난 회차 | 구분`. 규칙이 나중에 뒤집히면 지우지 말고 바뀐 회차를 적는다.

### 연표
`회차 | 작중 시점 | 사건 | 관련 캐릭터 | 이후에 영향을 주는 설정`.

### 표기 사전
`표기 | 금지 표기(오타·변형) | 처음 나온 회차 | 영어 표기 후보 | 일본어 표기 후보 | 메모`. 해외 표기 후보는 비워 둘 수 있다. launch-planner가 현지화 점검표에서 채운다.

## 3. 작업 규칙

- **짧게 인용한다.** 말투 예시처럼 꼭 필요한 곳만 한두 문장을 위치와 함께 인용한다. 원문을 길게 옮기면 설정집이 원고 사본이 된다.
- **창작하지 않는다.** 원작에 없는 설정을 채우지 않는다. 비어 있으면 `open-questions.md`로 보낸다.
- **충돌을 지우지 않는다.** 작가가 설정을 바꿨으면 두 버전을 회차와 함께 남긴다.
- **임시본을 표시한다.** 원고 없이 공개 줄거리·공식 소개만으로 만들었으면 `index.md` 맨 위에 "공개 자료 기반 임시본 — 일관성 검수 기준으로 쓰지 말 것"을 적는다.
- **분량을 조절한다.** 캐릭터는 판정에서 승인된 포맷에 나올 범위(예: 1부)부터 만든다. 범위를 `index.md`에 적는다.

## 4. 갱신

- 연재가 이어지면 `index.md`의 기준 회차 이후 원고만 읽고, 바뀐 항목을 `## 갱신 기록`에 `날짜 · 회차 · 항목 · 무엇이 바뀌었나`로 남긴다.
- 검수자의 `설정집 보강 필요` 요청은 해당 항목만 채운다.
- 피치 자료가 이미 이 설정집을 근거로 쓰였다면, 바뀐 항목을 리더에게 알려 검수 대상인지 확인하게 한다.
