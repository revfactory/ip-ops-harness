# IP 사업 운영 하네스 — 30초 쇼릴 스토리보드

- 규격: 1920×1080, 60fps, 30.0초, H.264 + AAC
- 박자: 128BPM, 1박 0.46875초, 1마디 1.875초, 16마디 = 30.0초. 모든 컷은 마디·박 경계에 맞춘다.
- 콘셉트: **IP 하나(빛 점)가 하네스를 통과하는 한 번의 카메라 이동.** 카메라는 끊기지 않고 아홉 정거장을 지나며, 마지막에 빠지면 지나온 길이 처음부터 고리였음이 드러난다. 고리 가운데에는 판정 원장이 있다.
- 비주얼 시스템
  - 색: 바탕 `#07080B`, 글자 `#F3F0E8`, 보조 `#5D6172`
  - 의미 색 3개: AI가 모은 근거 = 시안 `#36E2FF`, 사람의 결정 = 노랑 `#FFC933`, 기각·어긋남·잠금 = 빨강 `#FF4B3A`
  - 서체: 디스플레이 Paperlogy 900, 본문 Pretendard 600, 시스템 라벨 Meslo(고정폭)
  - 모티프: 빛 점(토큰). 판정 회의를 지나면 노란 고리가 붙고, 마지막 문장의 마침표가 된다.
