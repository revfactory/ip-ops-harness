## 확인하지 못한 것

스크립트 경고 3건과 정의·비교 기준 문제다.

1. 기준일 차이: 기준일(2026-11-10)이 시스템 날짜(2026-10-06)와 다르다. 승인·만료 판단은 기준일로 했다. 승인일(2026-10-15)이 시스템 날짜보다 뒤이므로 승인 기록의 날짜가 맞는지 확인이 필요하다.
2. 완독률 단위 혼재: 2026-08은 0~1, 2026-09는 %로 들어왔다. 스크립트가 1보다 큰 값을 %로 보고 맞췄다.
3. 재방문율 단위 혼재: 완독률과 같은 문제가 있고, 같은 방식으로 맞췄다.
4. 지표 정의 미확인: 완독률·재방문율의 정의 문장을 받지 못했다. 정의를 모르면 다른 IP와 비교하지 않는다.
5. 비교 IP 없음: 높다·낮다 표현을 쓸 수 없다. 같은 회차 규모의 비교 IP 집계가 필요하다.
6. 국가별 표의 "기타" 묶음(70명)은 최소 셀 기준으로 묶은 값이라 해석하지 않는다.

데이터 담당에게 물을 질문:

- 완독률과 재방문율의 정의는 무엇인가(예: 완독률 = 최신 회차까지 열람한 독자 ÷ 1화 열람 독자)?
- 2026-08과 2026-09의 단위가 다른데, 원본 값이 0~1과 %로 섞인 것이 맞는가?
- 비교용으로 같은 회차 규모(약 120화)의 IP 집계를 받을 수 있는가?
- 승인일 2026-10-15와 기준일 2026-11-10 관계에서 승인 기록의 날짜는 맞는가?
