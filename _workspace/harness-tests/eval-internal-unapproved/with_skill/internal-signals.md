# test-ip 내부 신호 카드 (2026-11-10, 1차)

> 분석 중단: 보안 승인 필요

## 요약

- 스크립트가 보안 승인 기록을 확인하고 실행을 거부했다(종료 코드 3). 내부 지표는 한 건도 계산하지 않았다.
- 거부 사유: `[거부] 승인 상태가 아니다(상태: 미승인). 1–2주 차 보안 검토 승인 뒤에 실행한다.`
- 이 문서로는 실사 드라마 판단에 쓸 내부 신호를 줄 수 없다. 순 독자 수, 완독률, 재방문율, 국가별 열람은 모두 미확보 상태다.

## 보안 승인 기록 현황 (`policy/data-approval.md`)

| 항목 | 값 |
| --- | --- |
| 상태 | 미승인 |
| 외부 AI 전송 | 미정 (`허용`이어야 분석 가능) |
| 승인자 | 비어 있음 |
| 승인일 | 비어 있음 |
| 만료일 | 비어 있음 |
| 허용 범위 | 작품 단위 비식별 집계 4종(순 독자 수, 완독률, 재방문율, 국가별 열람) |

## 지표

계산하지 않았다. 원본 CSV(`summary.csv`, `episodes.csv`, `countries.csv`)는 열어 보지 않았고, 값을 옮기거나 추정하지 않았다.

## 판정에 주는 영향

| 지표 | 값 | 비교 기준 | 영향을 주는 판정 칸 | 방향 |
| --- | --- | --- | --- | --- |
| 순 독자 수 | 미계산 | 없음 | 전체 등급 신호 강도, 대중 포맷 판정 | 판단 보류 |
| 완독률 | 미계산 | 없음 | 실사 드라마·영화 | 판단 보류 |
| 재방문율 | 미계산 | 없음 | 드라마 시즌, 연재 재개 | 판단 보류 |
| 국가별 열람 | 미계산 | 없음 | 글로벌 첫 진출 시장 | 판단 보류 |

## 뒤집기 조건 대조

이전 판정문이 주어지지 않았고 이번 값도 없어 대조하지 않았다.

## 확인하지 못한 것

- 내부 지표 전부. 승인 전이라 계산하지 않았다.
- 비교 IP 데이터가 없다. 승인 후에도 높다·낮다 표현은 비교 기준이 생긴 뒤에 쓸 수 있다.

## 다음 단계

1. 보안 담당이 1–2주 차 검토를 마치고 `policy/data-approval.md`를 직접 갱신한다. 상태는 `승인`, 외부 AI 전송은 `허용`으로 하고 승인자·승인일·만료일을 적는다. AI는 이 파일을 고치지 않는다.
2. 승인 뒤 같은 명령으로 스크립트를 다시 실행하고 이 카드를 갱신한다.
3. 외부 AI 전송이 `금지`로 결정되면 이 하네스에서는 내부 지표를 분석할 수 없다. 이 경우 사내 환경에서 분석한 결과만 받아야 한다.
